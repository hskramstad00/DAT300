# DAT300 – Applied Deep Learning

Coursework from **DAT300 Applied Deep Learning** at the Norwegian University of Life Sciences (NMBU), autumn 2026.

The course covers neural networks from scratch, CNNs, RNNs, autoencoders and generative models (VAE, GAN, Transformers), with a focus on building and training models on real data in Python.
